# `reports/` — Generated and submitted reports

| Folder | Content |
|--------|---------|
| `synthesis/` | Raw Vivado output: utilization and timing `.rpt` files, post-route reports, synthesized gate-level netlists |
| `progress_report/` | **Project Progress Report (Review 2)**, PDF plus HTML source and logo |
| `design_dossier/` | Detailed design and synthesis dossier, PDF plus HTML source |

## Notes

- Files in `synthesis/` are regenerated by the Tcl scripts in [`../scripts/`](../scripts/). Do not edit them by hand.
- PDFs are rendered from the HTML in each `source/` folder using headless Chrome.
- The numbers that [`../docs/RESULTS.md`](../docs/RESULTS.md) quotes come straight from `synthesis/`.
